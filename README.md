# Gerador de assinatura de e-mail VirtuGNL

Página pública para os colaboradores da VirtuGNL criarem a assinatura de e-mail no padrão da marca.

**Acesse:** https://antonioimperadeiro.github.io/assinatura-virtugnl/

1. Preencha nome, cargo, departamento, e-mail e telefone.
2. Clique em **Copiar assinatura**.
3. No Outlook, cole em **Configurações › Contas › Assinaturas** (novo Outlook) ou **Arquivo › Opções › Email › Assinaturas** (clássico).

Os dados digitados ficam apenas no navegador de quem usa a página; nada é enviado ou armazenado.

`logo-assinatura.png` é o logotipo carregado pelas assinaturas: não renomeie, mova ou apague este arquivo, ou as assinaturas já instaladas deixarão de exibir o logo.
